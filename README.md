# Number Analyzer

A simple JavaScript web app that analyzes a number and identifies whether it is Positive, Negative, Even, or Odd.

## Results

- 10 → Positive & Even
- 11 → Positive & Odd
- -10 → Negative & Even
- -11 → Negative & Odd
- 0 → Zero & Even

## Files

- `index.html` — webpage structure
- `style.css` — styling and responsive design
- `script.js` — number analysis logic

## JavaScript Concepts Used

- `const` and `let`
- DOM selection with `getElementById()`
- Input `.value`
- `Number()` conversion
- `onclick`
- `if / else if / else`
- comparison operators
- modulus `%`
- template literals
- `textContent`

## How to Run

Open `index.html` in any modern browser. No Node.js, npm, package, or server is required.
